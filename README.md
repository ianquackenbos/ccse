# Repaso CCSE 2026

Web de práctica para la prueba CCSE (conocimientos constitucionales y socioculturales de España) del Instituto Cervantes.

- Las 300 preguntas del *Manual de preparación de la prueba CCSE 2026*, con su clave de respuestas.
- Una explicación de «¿Por qué?» para cada pregunta.
- Práctica por tareas, repaso de errores y simulacros de 25 preguntas en 45 minutos.
- Revisión exportable en PDF.

Es un único archivo estático (`index.html`). El progreso se guarda en el navegador de cada usuario.

Las preguntas proceden del manual del Instituto Cervantes (© Instituto Cervantes). Este proyecto no es oficial ni está afiliado al Instituto Cervantes.
